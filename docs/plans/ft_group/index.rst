Group Fault-Tolerance Plans
===========================

Plans for keeping a PMIx group construct alive when a participant is lost —
in particular making daemon loss behave the same way client loss already
does.  Tracking issue: `#2510
<https://github.com/openpmix/prrte/issues/2510>`_.
