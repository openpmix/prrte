[no-helper]
PRRTE is running inside a PBS job, but cannot run the program it starts
its daemons with as tasks of the job:

  Program: %s
  Error:   %s

It is installed with PRRTE, so this installation is incomplete or was
moved. The daemons will be started some other way - with ssh where it is
available - and PBS will then not account for them or for anything they
run.
#
[helper-failed]
PRRTE could not start the program it starts its daemons with as tasks
of the PBS job:

  Program: %s
  Step:    %s
  Error:   %s
#
[daemon-failed]
A PRRTE daemon could not be started as a task of the PBS job.

  Local host:  %s
  Remote host: %s
  Reason:      %s

Check that "prted" and its libraries can be found on the remote host
with the PATH and LD_LIBRARY_PATH shown by "env" on this one, or use
--prefix to say where PRRTE is installed there.
