Set the working directory of the started processes. A relative path is
taken relative to the current working directory of the command, and
converted to an absolute path. Without this option (or
``--set-cwd-to-session-dir``), the processes start in the command's
current working directory. ``--wd`` is a synonym for ``--wdir``.
